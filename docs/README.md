# LLM Lab — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something and fixing something are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first rated recording.

**Something not working?** → [Troubleshooting](troubleshooting.md) — what you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Install, see the status bar, record a first call, rate it, find the trace file. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "No recordings yet", "Lab: paused", a call that is not recorded, a rating that cannot be saved. |

The [README](https://github.com/johannes-kaindl/llm-lab/blob/main/README.md) covers what the plugin records, what masking does and does not catch, every setting and the API for plugin authors.

---

`SMOKE.md` and `images/README.md` hold maintainer material (the GUI smoke checklist and the screenshot contract) and are not user documentation.

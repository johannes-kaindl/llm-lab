# Where the data lives

Recordings stay inside the vault, in the plugin's own configuration folder. Whether that folder is synced or backed up is a decision of the vault, not of the plugin. Nothing leaves the machine on its own.

Masking finds patterns — e-mail addresses, IBANs, phone numbers, credentials in URLs. It does not find names, addresses, diagnoses or relationships. The recording stays as confidential as the notes it was made from.
